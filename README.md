# 三國防禦塔 - 策略戰爭遊戲

一款融合三國歷史背景與典型防禦塔機制的策略遊戲。

## 🎮 遊戲特色

### 核心機制
- **塔防遊戲**: 放置各種防禦塔來抵禦敵人波次
- **歷史背景**: 以著名三國戰役為關卡（赤壁、官渡、長坂坡等）
- **塔系統**: 6位三國名將塔 + 6種士兵防禦塔

### 將領塔 (將領級防禦)
1. **諸葛亮** 🧙
   - 遠程法術師，能減速敵人 50%，持續 2 秒
   - 成本: 200 金幣
   - 屬性: 木系 (蜀)

2. **關羽** 🗡️
   - 近距離群攻，範圍 80
   - 成本: 180 金幣
   - 屬性: 火系 (蜀)

3. **黃忠** 🏹
   - 超遠程狙擊，30% 暴擊率 (2倍傷害)
   - 成本: 250 金幣
   - 屬性: 金系 (蜀)

4. **呂蒙** 🎖️
   - 智將控制，25% 機率眩暈敵人 1.5 秒
   - 成本: 200 金幣
   - 屬性: 水系 (吳)

5. **張飛** 🛡️
   - 高防禦型，減少 60% 傷害
   - 成本: 220 金幣
   - 屬性: 土系 (蜀)

6. **曹操** 👑
   - 戰略家，為 250 範圍內友方塔提升 20% 傷害
   - 成本: 300 金幣
   - 屬性: 金系 (魏)

### 士兵塔 (基礎防禦)
1. **步兵** 🪖 - 基礎防禦單位 (50 金幣)
2. **弩兵** 🏹 - 單體精準傷害 (80 金幣)
3. **投石車** 🎯 - 範圍爆炸傷害 (120 金幣)
4. **騎兵** 🐴 - 移動快速防線 (100 金幣)
5. **法師塔** ✨ - 法術傷害 (110 金幣)
6. **火砲塔** 🔥 - 持續燃燒傷害 (140 金幣)

## 📊 策略系統

### 五行相克機制
遊戲採用傳統五行系統来實現敵我配置的複雜互動:

```
木 → 土 (1.3倍) / 克制金 (0.7倍)
火 → 金 (1.3倍) / 克制水 (0.7倍)
土 → 水 (1.3倍) / 克制木 (0.7倍)
金 → 木 (1.3倍) / 克制火 (0.7倍)
水 → 火 (1.3倍) / 克制土 (0.8倍)
```

### 地形系統
不同地形對戰鬥產生影響:

- **平原** (官渡之戰)
  - 基礎地形，無特殊加成
  - 適合标准策略布局

- **水域** (赤壁/淝水/夷陵之戰)
  - 火系塔傷害提升 30%
  - 射程塔射程降低 20%
  - 適合火系策略

- **山地** (長坂坡之戰)
  - 射程塔射程降低 30%
  - 近戰塔更有優勢
  - 適合近戰密集防線

### 敵人系統
- **普通士兵**: 基礎敵人，廉價但脆弱
- **精英士兵**: 更強硬的雜兵
- **斥候**: 移動快速但血量低
- **重裝兵**: 防禦高，吸收傷害
- **隊長**: 中層精英敵人
- **Boss (猛將)**: 張魯、董卓、呂布等強大敵人

### 特殊效果
- **減速**: 敵人移動速度降低 (25-50%)
- **眩暈**: 敵人暫停移動 (1-1.5秒)
- **燃燒**: 持續傷害效果 (3秒)

## 🎯 遊戲玩法

### 基礎流程
1. **選擇關卡**: 選擇歷史戰役進入遊戲
2. **放置塔**: 點擊已選擇的塔卡片，在畫布上放置
3. **開始波次**: 按 "開始波次" 按鈕開始敵人攻擊
4. **操控戰鬥**: 使用暫停、速度提升等功能操控
5. **擊敗Boss**: 完成所有5波敵人浪潮

### 資源管理
- **黃金 💰**
  - 初始: 500 (+ 關卡級數 × 100)
  - 獲得: 擊殺敵人獲得金幣
  - 消耗: 放置塔或升級塔

- **生命值 ❤️**
  - 初始: 100
  - 損失: 敵人通過防線 -10 生命
  - 失敗: 生命值降至 0

### 升級系統
- **塔升級**: 每個塔可升級，提升傷害和血量
- **升級成本**: 約 1.5 倍當前塔成本

## 🏆 遊戲得分
得分 = 擊殺敵人獲得的總黃金 + 地形加成 × 難度係數

## 🎮 控制方式
- **選擇塔**: 點擊側邊欄的塔卡片
- **放置塔**: 在畫布上點擊選擇的位置
- **選擇塔**: 點擊已放置的塔查看詳細信息
- **升級塔**: 选擇塔後按 "升級" 按鈕
- **暫停/繼續**: 按 "暫停" 按鈕
- **加速遊戲**: 按 "2x 速度" 按鈕

## 📝 技巧與策略

1. **陣營搭配**: 混合不同陣營的塔以應對各類敵人
2. **地形適應**: 根據地形選擇合適的塔配置
3. **經濟管理**: 平衡塔放置和升級投資
4. **早期防守**: 前期敵人較弱，使用便宜的士兵塔
5. **中期升級**: 積累資源升級核心塔
6. **後期集火**: Boss出現時集中火力
